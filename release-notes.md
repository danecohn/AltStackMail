AltStack Mail & Calendar 1.0.1

An AltStack LLC client built from the Tuta browser client at commit d589cf8c6f6855a314db39e059cffb464f805e19, with the upstream Mail and Calendar interfaces, AltStack branding and Alpine chrome.

Use an AltStack account for the AltStack portal and a Tuta account for your mailbox and calendar. Tuta remains the encrypted email/calendar service and applies its own account plans. Files saved to Warehouse use your shared AltStack 2 GB Free / 8 GB Plus file allowance.

Installers for Windows x64/ARM64, macOS Intel/Apple Silicon and Linux x64/ARM64. These applications use a sandboxed host for the same browser client; upstream's native desktop bridge is not used on unsupported architectures. Windows installers are unsigned. macOS builds are not notarized by Apple yet, so after downloading, open System Settings > Privacy & Security and choose Open Anyway for AltStack Mail & Calendar (or run: xattr -dr com.apple.quarantine "/Applications/AltStack Mail.app"). Downloads and updates are provided through this release and the AltStack downloads page.
