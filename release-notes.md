AltStack Mail & Calendar 1.0.4 — Artemis Softworks LLC

Produced and developed by Artemis Softworks LLC, founded by Demetria Althea Cohn. This release refines the blue cloud interface and introduces the original crescent-and-bow identity, Artemis application artwork, and current publisher credits. Existing accounts, data locations, application identifiers and upstream Tuta notices are retained.

macOS packages continue to use ad-hoc signing and strict verification; they are not Apple-notarized. Windows packages remain unsigned. The publisher identity is application metadata, not a claim of an Apple or Microsoft signing certificate.

The 1.0.2 Mac signature repair remains included. Upstream Tuta source, GPL license and original contributors remain credited.
